# Agnel Spark Fest

Build a modern, premium, party-themed event website for Fr. Agnel Polytechnic, Vashi to promote the college event "Freshers' Party '26".

The website is frontend only.
There should be NO backend, NO database, and NO authentication.
All registrations should happen through Google Forms.

The website should be fully responsive for desktop, tablet, and mobile.

The overall theme should feel like a college party/night event.

Overall Goal

The final result should feel like a premium college event landing page, comparable to a professional festival website. It should immediately excite first-year students to participate. The experience should be immersive, with a vibrant party atmosphere, elegant animations, and intuitive navigation. The design should strike a balance between youthful energy and professionalism, reflecting the reputation of Fr. Agnel Polytechnic and its Student Council while encouraging registrations for Freshers' Party '26.
